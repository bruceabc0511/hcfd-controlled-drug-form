# 新竹縣政府消防局 管制藥品損壞/遺失事故報告單 電子表單與線上傳簽系統

本專案依原紙本 PDF《新竹縣政府消防局管制藥品 □損壞 □遺失 事故報告單》1:1 數位化設計，採用 **`#FF5809`** 消防橘紅作為 CSS 主色調，支援**事故人員線上填報**、**四級主管連結傳簽電子填寫**、**Google 雲端試算表／雲端硬碟同步**，以及**全體主管填畢後一鍵列印 A4 紙本（保留簽章欄蓋章）**。

## ✨ 功能亮點

1. **四級主管意見電子化填寫 ＋ 簽章欄保留紙本蓋章**：
   - 「分隊長主管意見（含責任判定單選、意見、日期）」、「醫療指導醫師意見（意見、日期）」、「緊急救護科主管意見（意見、日期）」、「醫院藥劑科主任意見（處理方式、其他建議、日期）」皆可於網頁上直接電子化填寫。
   - 列印 A4 紙本或匯出 PDF 時，電子填寫之意見與日期會自動以**藍色（`#0052D9`）**標示，而各欄位的「**簽章：**」區塊則維持紙本空白，供列印後蓋章。
2. **專屬連結傳簽流程（`?id=單號`）**：
   - **步驟 ① 事故人員填報**：填寫事故內容與照片後，點擊「**🔗 儲存雲端並複製傳簽連結**」，即可將連結透過 LINE 或公務信箱傳給各級主管。
   - **步驟 ②～⑤ 四級主管填寫**：主管點擊連結即自動從 Google 雲端載入該筆報告，填寫完所屬主管意見欄後，點擊「**🔗 儲存雲端並複製傳簽連結**」即可更新同筆單號並傳給下一位主管。
   - **步驟 ⑥ 事故人員列印紙本蓋章**：待進度條 5 個節點全數亮起綠燈後，事故人員再次打開同一連結，點擊「**🖨️ 列印 A4 紙本 / 匯出 PDF**」即可印出完整紙本送交蓋章。
3. **1:1 紙本結構與 A4 一式三聯列印／PDF 匯出**：
   - 可選擇「**一式三聯**（自動產生第一聯醫院藥劑科留存、第二聯消防局緊急救護科留存、第三聯分隊留存）」或「**單頁列印**」。
   - 「檢附文件查檢表」維持標準紙本方框（`□`），供列印後手寫勾選。
4. **支援多人並行傳簽與智慧差分合併（防止覆蓋清空）**：
   - 當同一傳簽連結同時發送給多位主管填寫時，系統採用前端「修改欄位差分比對（Dirty Fields）」搭配 GAS 後端「智慧差分合併（Smart Merge）」與排它鎖（`LockService`）。
   - 各級主管同時間各自填寫所屬意見（例如分隊長、指導醫師、救護科同時開頁面），送出時**僅更新自身編輯之主管欄位**，絕不會因後送出者載入時的空白欄位而覆蓋其他主管的填寫結果。
   - 介面提供「**🔄 重新整理進度**」按鈕並支援瀏覽器分頁切換自動背景同步，隨時載入最新傳簽進度。
5. **預設連線與隱藏式管理員設定（防誤觸保護）**：
   - 系統已內建預設 Google Apps Script 雲端後端網址，全體同仁與各級主管開啟傳簽連結即自動連線。
   - 頂部工具列之「☁️ 雲端設定」按鈕與設定視窗預設已完全隱藏，徹底防止人員傳簽時誤觸改動後端網址。
   - 管理人員如需調整雲端後端網址或手動同步清單，可透過網址參數 `?admin=1` 或**連續點擊左上角「藥」字 Logo 8 次**快速解鎖彈出管理視窗。
6. **藥品清單 Google 試算表線上動態同步（方案 C）與品項鎖定綁定**：
   - **品項規格與管制級別鎖定綁定**：選擇藥品（中文或英文）後，「規格」與「管制級別」會自動帶入並轉為唯讀鎖定狀態（🔒 隨藥品品項自動綁定），禁止使用者任意修改，確保管制法規與藥品規格之嚴謹性。
   - **雲端試算表集中維護（方案 C）**：
     - Google 試算表後端會自動建立並維護「**藥品品項清單**」工作表。
     - 欄位包含：`藥品中文名稱`、`藥品英文名稱`、`規格`、`管制級別`、`計量單位`、`狀態 (啟用/停用)`。
     - 管理者可隨時在試算表中新增藥品、修改規格或將已下架藥品之狀態改為「停用」。
     - 前端表單開啟或重新整理時，會自動非同步向 Google 試算表拉取最新藥品清單並快取於瀏覽器，下拉選單自動同步更新！
