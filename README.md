# 新竹縣政府消防局 管制藥品損壞/遺失事故報告單 電子表單系統

本專案依原紙本 PDF《新竹縣政府消防局管制藥品 □損壞 □遺失 事故報告單》1:1 數位化設計，採用 **`#FF5809`** 消防橘紅作為 CSS 主色調，支援**純本機離線填寫**、照片拖曳上傳預覽、本機草稿與歷史紀錄儲存、JSON 匯出入，以及一鍵輸出原貌 A4 一式三聯紙本列印／PDF 匯出。

---

## 📁 檔案結構

- [index.html](file:///d:/Anti/index.html)：主網頁介面（免安裝伺服器，直接雙擊即可在瀏覽器開啟使用）
- [styles.css](file:///d:/Anti/styles.css)：`#FF5809` 主色調響應式樣式表（跨裝置多解析度 RWD）與 `@media print` A4 紙本原貌列印排版規則
- [app.js](file:///d:/Anti/app.js)：表單互動連動、民國年自動換算、常用選單自動學習、照片壓縮預覽、LocalStorage 草稿／歷史紀錄與 JSON 匯出入
- [RESPONSIVE_DESIGN_GUIDE.md](file:///d:/Anti/RESPONSIVE_DESIGN_GUIDE.md)：跨裝置多解析度 RWD 與 A4 列印防跑版設計規範手冊

## ✨ 功能亮點

1. **1:1 紙本結構與 A4 一式三聯列印／PDF 匯出**：
   - 可選擇「**一式三聯**（自動產生第一聯藥劑科、第二聯救護科、第三聯分隊留存共 3 頁 A4）」或「**單頁列印**」。
   - 列印與匯出 PDF 時自動隱藏網頁操作按鈕，將西元日期自動轉換為公文標準「民國年、月、日」，並將**使用者填入的值以藍色（`#0052D9`）標示**。
2. **四級主管意見與檢附文件保留紙本手寫欄位**：
   - 「分隊長主管意見」、「醫療指導醫師意見」、「緊急救護科主管意見」、「仁慈醫院藥劑科主任意見」及「檢附文件查檢表」均設計為標準紙本手寫與手寫勾選區塊，列印後供各級長官親筆簽核與勾選。
3. **智慧填表輔助與常用選單自動記憶**：
   - 內建新竹縣政府消防局各分隊選單與常見管制藥品自動帶入，並會**自動學習使用者手動填入的新項目**（藥品中英文名、級別、規格、單位、分隊、報案受理單位）加入下拉選單中。
   - 單選「損壞」或「遺失」時自動連動「報案證明」，並提供一鍵套用報告內容範本與日期一致性檢核提醒。
4. **照片一、照片二拖曳上傳與自動最佳化**：
   - 支援點擊或拖曳圖片上傳，自動透過 Canvas 壓縮最佳化並直接嵌入 A4 表格列印。
5. **純本機草稿、歷史紀錄與 JSON 備份**：
   - 所有資料皆安全保存在本機瀏覽器 `LocalStorage`（不經過外部雲端），支援隨時匯出／匯入 `.json` 草稿備份檔與載入本機歷史紀錄。
